## 🌟 Executive Overview
**Safe Bloom** is an offline-first, zero-knowledge menstrual, fertility, and pregnancy tracking application built with an uncompromising commitment to user privacy and data sovereignty. Safe Bloom operates with zero tracking scripts, zero third-party analytics, zero cloud databases, and zero external push servers. 

Every health metric, cycle date, symptom log, and private note is encrypted locally on the device with **SQLCipher AES-256-GCM** backed by hardware cryptographic keys (Android Keystore / iOS Keychain).

---

## 🚀 Key Features in v1.0.0

### 1. 🔐 Zero-Knowledge Security & Privacy Architecture
* **Hardware-Backed AES-256 Encryption:** All database records are encrypted with SQLCipher using keys generated and protected inside the device's secure hardware element.
* **Biometric Lock Screen:** Biometric authentication (Fingerprint, Face Unlock, Touch ID) guards app entry on cold launch, app switching, and returning from the background.
* **Screenshot & Screen Recording Prevention (`FLAG_SECURE`):** Configurable in Settings to block OS-level screen capture, external recordings, and recent app thumbnail previews.
* **Zero-Knowledge Nuclear Purge:** Single-tap emergency data wipe that cryptographically shreds the database, wipes Keystore keys, and purges all local cache without recovery traces.
* **Database Recovery Protocol:** Built-in cryptographic integrity checks with automated repair and encrypted vault recovery paths if hardware keys become desynchronized.

---

### 2. 🌸 Intelligent Cycle & Fertility Prediction Engine
* **Dynamic Moving-Average Analytics:** Continuously learns and refines cycle length and period duration predictions from historical user data.
* **Four-Phase Hormonal Tracking:** Real-time visual timeline and calendar breakdowns for:
  * **Menstrual Phase** (Period days)
  * **Follicular Phase** (Estrogen rise & energy building)
  * **Ovulatory Phase** (Peak fertility window & ovulation countdown)
  * **Luteal Phase** (Progesterone surge & PMS insights)
* **Spotting & Irregular Flow Isolation:** Dedicated spotting classification that records light bleeding without creating phantom cycles or distorting future period predictions.
* **Retroactive Cycle Editing:** Full past cycle management with calendar date adjustments, duration edits, and instant downstream metric recalculations.

---

### 3. 👶 Try to Conceive (TTC) & Pregnancy Companion Mode
* **Try to Conceive (TTC):** Pinpoints the 6-day fertile window with peak ovulation countdowns and conception guidance.
* **Full Pregnancy Tracking Mode:**
  * Gestational age calculation in weeks and days from Last Menstrual Period (LMP) or conception.
  * Estimated Due Date (EDD) projections using clinical algorithms (Naegele's rule).
  * Trimester progression bar (1st, 2nd, and 3rd Trimesters).
  * Weekly baby size comparisons with fruits and vegetables.
  * Trimester-tailored health, nutrition, and wellness guides.
  * **Automatic Alarm Suppression:** Intelligently mutes menstrual and ovulation reminders while Pregnancy Mode is active.

---

### 4. 📝 Daily Wellness, Symptom, & Hydration Logging
* **Comprehensive Symptom Library:** Categorized logging for Physical symptoms (cramps, headaches, bloating), Mood, Energy levels, Cervical Mucus, and Flow intensity.
* **Interactive Water Intake Tracker:** Daily hydration logging with quick-add increments, daily target progress rings, and historical hydration stats.
* **Interactive Calendar:** Multi-month calendar view with distinct color-coded indicators for confirmed periods, predicted cycles, peak fertility, and logged daily symptoms.

---

### 5. 🔔 100% Local Device Notifications & Reminders
* **Zero Cloud Push Infrastructure:** All alarms are scheduled directly with the local OS alarm clock manager (`flutter_local_notifications: 19.5.0` + `timezone: 0.10.1`).
* **Configurable Alert Suite:**
  * Period Prediction Alert (2 days in advance).
  * Peak Fertility / Ovulation Alert (1 day in advance).
  * Daily Health Logging Reminder (customizable time of day).
  * Periodic Hydration Reminders (11:00 AM, 3:00 PM, 7:00 PM).
  * New Wellness Guides & Articles.
* **Discreet Lock Screen Mode:** Automatically masks sensitive reproductive health terms with neutral, private self-care prompts on lock screens.
* **Real-Time Permission Detection:** Directly queries native `NotificationManagerCompat` to reflect OS notification permission status and provides direct system settings navigation.
* **Developer System Diagnostics:** In-app testing panel with individual alert preview chips for immediate verification.

---

### 6. 📊 Clinical Reports & PDF Medical Export
* **Ob/Gyn Consultation Report:** Generates medical-grade, formatted PDF summaries including cycle variances, flow statistics, symptom trends, and spotting frequency.
* **Direct Print & Share:** Rendered entirely on-device and ready for direct printing or secure sharing with healthcare providers.

---

### 7. 🗄️ End-to-End Encrypted Vault Backup & Restore
* **Passphrase-Protected Encrypted Vaults:** Exports a zero-knowledge JSON vault encrypted using PBKDF2-HMAC-SHA256 and AES-GCM.
* **Air-Gapped Portability:** Backups can be moved via offline storage, USB, or local file transfer without sending raw bytes to any remote server.
* **Welcome Flow Restoration:** Single-tap backup vault import directly from the onboarding screen.
